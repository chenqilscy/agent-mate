## 问题

WB-035 为「侧栏不刷屏」把自动化会话挡出「任务」列表（[`Sidebar.tsx:65`](../../src/components/layout/Sidebar.tsx#L65)
`s.kind !== 'automation'`），只在「自动化」页留了运行历史入口。但由此产生两个可见性缺口：

- **未绑定工作空间**的自动化：其运行会话在侧栏**哪儿都不出现**（被「任务」过滤掉，也不属于任何「空间」）。
- **绑定了工作空间**的自动化：其会话混进对应「空间」（`sessionsOf` 未按 kind 过滤），无标识、也可能刷屏该项目。

即：绑定的「藏」在空间里、未绑定的彻底看不到，不一致且难找。

## 触发场景

1. 建一条**不绑定工作空间**的自动化，等它运行几次。
2. 侧栏「任务」「空间」都找不到这些会话；只能进「自动化」页看运行历史。

## 影响

P2：可达性缺口 + 不一致。会话真产出、有真实内容，但侧栏找不到，用户以为「执行完的会话丢了」。

## 建议修法

按选定方案：侧栏加一个与「任务/空间」平行的**可折叠「自动化」分组**，统一列近期自动化运行会话
（不论是否绑定空间），并从「任务/空间」里去重：

- Sidebar：新增 `autoRuns = sessions.filter(s => s.kind === 'automation')`，**按 updated_at 倒序、限近 N 条**
  （如 10）显示，复用既有 `.sb-sec`/`.sb-list`/`.sb-task` 分组样式，可折叠（`autoOpen` 状态）；点条目
  `openSession` + 切 chat。
- 去重：`sessionsOf` 补 `&& s.kind !== 'automation'`，让绑定空间的自动化会话从「空间」移到「自动化」分组，
  避免两处重复。「任务」原过滤保留。
- 纳入既有搜索/状态筛选（`matchSession`）与折叠交互，不新增 CSS（或极少量 token 化）。
- 每条自动化的**完整**运行历史仍在「自动化」页卡片/编辑器（WB-035/036），侧栏分组只是「近期快捷入口」。

非目标：不取消 WB-035 的运行历史入口；不无上限铺满侧栏（务必限条数，避免重回「刷屏」）。

## 验证

- `npx tsc --noEmit` 通过。
- 浏览器：未绑定/绑定的自动化运行后，都在侧栏「自动化」分组里可见并可点开；「空间」下不再重复出现；
  「任务」不含自动化会话。分组可折叠、限条数、明暗双主题正常。
- 回归：普通对话仍在「任务」、项目会话仍在「空间」；搜索/状态筛选对新分组生效。
