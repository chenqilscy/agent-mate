## 问题

对照目标设计，自动化视图（已有自动化时）与 clone 现状差异较大：

- 目标顶部是 **定时任务 / 运行记录** 两个 tab + 右侧工具条（搜索自动化/记录、批量管理、从模版添加、
  ＋添加自动化）；clone 现状是「自动化」标题 + 单个「新建」按钮。
- 目标「定时任务」tab 是**紧凑列表**（「当前」分组，每行：名称 · 工作空间 · 频率 · 下次执行时间），
  clone 现状是 `.auto-card` **卡片网格**。
- 目标把模板放到**独立的「从模版添加」页**（面包屑「自动化 / 从模版添加」），从工具条进入；
  clone 现状把模板**内联**在列表下方（「从模板入手」）。
- 空态（无自动化）：仍是提示 + 模板网格（沿用目标空态）。

## 触发场景

1. 已添加过自动化 → 进「自动化」页，看到的应是 tab + 工具条 + 紧凑列表，而非卡片 + 内联模板。
2. 想从模板加 → 应进独立「从模版添加」页。

## 影响

P2：视觉/信息架构与目标不一致；不影响功能正确性。

## 建议修法

- `AutomationView` 重构为：
  - **空态（0 条）**：沿用「开启你的第一个自动化任务吧」+ ＋添加 + 模板网格。
  - **非空**：顶部 tab（定时任务/运行记录）+ 工具条（搜索、从模版添加→独立页、＋添加自动化→空白编辑器）。
    - **定时任务** tab：紧凑列表（「当前」分组，行 = 图标 + 名称 + 工作空间名 + 频率/下次执行；
      行点击进编辑器；行内保留 启用开关 / ⋯ 菜单）。
    - **运行记录** tab：见 WB-043。
  - **从模版添加** 独立页（面包屑「自动化 / 从模版添加」，模板网格，点模板 → 预填编辑器）。
- 搜索框过滤定时任务列表（按名称）。
- 复用既有 class 与 token（tab 用 `.seg2` 或既有 tab 样式；行复用 `.sb-task`/新增少量 token 化行样式），
  明暗双主题。

非目标（另开 issue）：**批量管理**（多选 + 批量启用/停用/删除，WB-045 备忘）；编辑器的
Loadout/频率扩展/权限/微信推送（WB-036 已列后续）。

## 验证

- `tsc` 通过。
- 浏览器：有自动化时显示 tab + 工具条 + 紧凑列表（当前分组、名称·工作空间·频率·下次执行）；
  从模版添加进独立页、点模板进预填编辑器；空态显示提示 + 模板。明暗双主题正常。
- 回归：编辑器（WB-036/037/038/039）、卡片菜单动作（立即运行/编辑/运行历史/删除）仍可用；
  侧栏自动化分组（WB-041）不受影响。
