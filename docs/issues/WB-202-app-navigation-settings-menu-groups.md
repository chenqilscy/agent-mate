## 问题

应用左侧一级导航把任务入口、工作对象、能力目录和自动化配置连续平铺；设置中心也把账户、应用偏好、
智能体能力、数据安全与帮助连续列出。功能数量增加后，相邻项只靠图标和顺序区分，用户难以判断某项是
“日常使用”“能力配置”还是“数据与安全设置”。

## 触发场景

用户需要配置模型或记忆时，要在 11 个等权设置项中扫描；需要从日常任务切换到技能/连接器管理时，
左侧菜单没有视觉分区，项目、专家、技能、连接器和自动化看起来属于同一层用途。

## 影响

P2：功能都可达，但导航认知成本随功能增加持续上升，设置弹窗也缺少稳定的管理心智模型。

## 建议修法

- 左侧导航按“开始 / 工作 / 能力”组织，保持现有 URL、选中态与点击行为不变；任务、空间和运行历史仍在其独立数据区。
- 设置中心按“账户 / 应用设置 / AI 与能力 / 数据与安全 / 支持”分组，并把同类项相邻排列。
- 分组标题使用既有文字色、间距和导航 token；不增加新页面、不制造假功能。
- 窄高窗口需保持导航可滚动，明暗主题下分组标题、选中态与分隔关系清晰。

## 验证

- 左侧每个功能仍进入原页面，活动项正确；设置中心 11 个功能均保留且切换内容不变。
- 明暗主题、1440×900 与 800×700 下无水平溢出、菜单不被裁切，键盘可达不回归。
- `npx tsc --noEmit`、`npx vite build`、`git diff --check` 通过。

## 处理记录（2026-07-20）

- 左侧一级导航改为“工作 / 能力 / 资源”三组：工作承载新建任务、助理、项目、自动化；能力承载专家、技能、连接器；资源承载文件与知识入口。
- 资源弹层再分“文件与文档 / 发现”，保留我的文件、金山文档、知识库、灵感四个真实页面入口。
- 设置中心改为“账户 / 应用设置 / AI 与能力 / 数据与安全 / 支持”五组，11 个功能项全部保留；命名统一为通用设置、模型管理、助理配置等用途导向名称。
- 清理重复入口：模型管理不再混在资源菜单；账号菜单只保留“设置中心”，外观和帮助统一由设置中心承载；删除已无调用方的 `modelConfigOpen` 全局状态。
- Playwright + Edge 实测 6 个一级页面和 4 个资源页面路由全部正确；11 个设置项逐一切换成功。
- 浅色/深色、1440×900、800×700 和窄屏抽屉通过；设置导航及页面水平溢出均为 0，任务列表保持独立滚动。
- `npx tsc --noEmit`、`npx vite build`、`git diff --check` 通过。
