## 问题

「计划」看板的「添加数据源」按钮（`ProjectWork.tsx:35`）当前只 `toast('添加数据源（后续接连接器）')`。目标设计（用户截图）里它是一个完整弹窗：空态（「还没有外部数据源」+ 添加）→ 数据源选择器（TAPD 定时导入 / CNB 定时导入 / GitHub 事件触发，带「去授权 / 选择」）。

真实的外部数据源同步（TAPD/CNB/GitHub 授权 + 定时/事件导入）是**大型外部集成**，本期不实现真实同步。铁律「不硬编码、不模拟」要求：**不能伪造授权成功或造假导入数据**。因此本期只做**界面占位**，并按项目占位惯例（见 WB-023：文案「敬请期待」）明确标注未接真实同步。

## 触发场景

进入项目 → 计划 tab → 点「添加数据源」：只弹一句 toast，无选择界面。

## 影响

P2：目标设计里的入口缺失；但真实同步非本期目标，做成占位即可，不得伪造。

## 建议修法

- 把 toast 换成弹窗（复用 `.np-overlay/.np-modal`）：
  - 空态：「还没有外部数据源」+「添加」→ 进入数据源选择列表。
  - 列表：TAPD / CNB / GitHub 三项，带类型徽标（定时导入 / 事件触发）与图标，沿用 `.pkc-row` 或原型卡片样式。
- **诚实占位**：每项的「去授权/选择」不进入伪造流程，而是明确提示「敬请期待 / 即将支持」（`toast` 或 disabled 态），与 `NP_CONNS` 连接器体系区分清楚（这里是外部数据源，不是会话工具连接器）。
- 不新增后端、不落库、不造数据。
- 视觉零重设计；暗色 `body.dark` 覆盖。

## 验证

- `npx tsc --noEmit` 过。
- 浏览器实测：点「添加数据源」弹出空态→选择列表；点任一「去授权/选择」得到「敬请期待」提示、不产生任何假数据/假状态；明暗双主题弹窗可读。
