## 问题

连接器页右上角显示“自定义连接器”，点击只调用 `toast('自定义连接器')`，没有编辑器、持久化 API 或运行时注册。
这会让用户误以为 App 支持创建本机连接器。

## 触发场景

App → 连接器 → 自定义连接器 → 只出现同名提示，页面和数据均无变化。

## 影响

P2：公开入口承诺了不存在的能力，违反不硬编码、不模拟铁律。

## 建议修法

在完整的本机自定义连接器模型和凭据安全方案落地前，移除该假入口；Server/Console 的平台连接器目录管理
继续作为已实现的运营入口，不影响现有连接器浏览、配置与召唤。

## 验证

- App 连接器页不再出现不可用的“自定义连接器”按钮；
- 专家“我的专家”和技能“添加技能”真实入口保持不变；
- 连接器卡片、详情、配置和召唤路径回归通过。

## 处理记录（2026-07-21）

- 移除连接器页右上角仅弹 toast 的“自定义连接器”按钮；专家“我的专家”和技能“添加技能”入口保持不变。
- App 真机验收确认该伪入口数量为 0，6 张真实连接器卡仍正常显示；技能/连接器实时功能回归 15/15 通过。
