## 问题

WB-216 已把 AgentMate 推荐技能改为“先真实安装，再允许读取内容与运行”，但功能门禁仍直接把 `excel-csv`、
`web-access` slug 放进 loadout。未安装时后端正确报告“技能未就绪”，C1 却只检查展示名而误判通过；C6 又因
没有 `analyze_csv` 工具事件而失败，形成同一测试内的假阳性与假阴性。

## 触发场景

本机未安装 `excel-csv` 时运行 `test_C_skills_connectors`：C1 显示通过，实际 label 是“技能未就绪”；C6
没有工具事件，但模型可能从上下文猜出“4”而让结果断言通过。

## 影响

P1：技能真执行的主回归门禁失真，既可能掩盖未安装技能未生效，也会让正确的安装模型持续红灯。

## 建议修法

- 测试开始时读取安装态，仅为缺失的目录技能执行真实安装；结束时只卸载本测试安装的技能。
- C1 同时断言不存在“技能未就绪”；C5/C6 继续要求真实工具事件和真实结果。
- 清理路径放在 `try/finally`，避免测试失败污染用户安装态。

## 验证

- 在 `excel-csv` 未安装和已安装两种状态下分别运行，均 15/15 通过；
- 测试结束后安装态与执行前一致；
- C1 不再把“技能未就绪”误判为加载成功。

## 处理记录（2026-07-21）

- 功能门禁启动时读取真实安装态，只安装缺失的 `web-access`/`excel-csv`，并用退出清理恢复测试前状态。
- C1 增加“不得出现技能未就绪”断言；C5/C6 继续同时校验工具事件与真实结果。
- 在缺失安装态运行实时回归 15/15 通过，测试安装的技能已自动卸载，测试账号/项目完成清理。
